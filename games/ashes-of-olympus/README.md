# Пепел Олимпа

Изометрическая мифологическая action-RPG в браузере и на Android. Это своя игра в жанре, без чужих имён, карт и графики.

- Играть в браузере: откройте `index.html`.
- Android: APK собирает GitHub Actions (`.github/workflows/olympus-apk.yml`) и выкладывает в релиз `olympus-latest`.

## Что внутри

- **6 мастерий:** Война, Защита, Охота, Тень, Стихии, Дух. В каждой по 5 умений: 3 активных и 2 пассивных. Шкала ранга мастерии открывает умения на 1, 4, 8 и 12 ранге.
- **Вторая мастерия** выбирается на 6 уровне. Из пары получается класс: всего 21 вариант, например Страж, Ассасин, Некромант, Оракул.
- **Изометрический мир:** острова с обрывами, вода, лава и облака. Дороги, руины, город с торговцем и оракулом, обелиски-телепорты, сундуки и амфоры, туман войны на карте.
- **Управление в духе жанра:** клик по земле — идти (с поиском пути), клик по врагу — атаковать. На телефоне есть джойстик и касания.
- **Снаряжение:** 9 слотов (оружие, щит, голова, торс, ноги, руки, 2 кольца, амулет), 6 типов оружия, 5 редкостей, легендарные предметы с цитатами, требования по уровню.
- **Враги:** чемпионы со свойствами (огненный, быстрый, каменнокожий, кровопийца, ледяной), вожак логова в каждом акте как побочное задание, боссы с двумя фазами.
- **Кампания:** 4 акта основной игры и 3 дополнения, которые можно включать и выключать: «Северные руны», «Затонувшая Атлантида», «Врата Аида».
- **Сложности:** Обычный, Эпический, Легендарный.
- **Звук и автосохранение:** синтезированные звуки и своя музыка в ладу каждого акта, сохранение в браузере.

## Костюмы и коды

Любой костюм открывается бесплатно в меню «Костюмы и коды» или кодом. Регистр не важен, у каждого есть русский вариант.

| Костюм | Коды | Бонус |
|---|---|---|
| Ниндзя | `NINJA`, `НИНДЗЯ`, `SHINOBI` | +12% к скорости бега, +5% к шансу крита |
| Самурай | `SAMURAI`, `САМУРАЙ`, `BUSHIDO` | +10% к урону |
| Спартанец | `SPARTA`, `СПАРТА`, `MOLONLABE` | +20% к броне |
| Фараон | `PHARAOH`, `ФАРАОН`, `RA` | +15% к энергии |
| Викинг | `VALHALLA`, `ВАЛЬХАЛЛА`, `SKAL` | +12% к здоровью |
| Пират | `PIRATE`, `ПИРАТ`, `YARR` | +30% золота, выше шанс найти предмет |
| Некромант | `NECRO`, `НЕКРОМАНТ`, `LICH` | 3% вампиризма |
| Киборг | `CYBORG`, `КИБОРГ`, `2077` | +12% к скорости атаки |
| Гладиатор | `ARENA`, `АРЕНА`, `GLADIATOR` | +8% к урону и здоровью |
| Феникс (секретный, только по коду) | `PHOENIX`, `ФЕНИКС` | регенерация, одно воскрешение за акт |
| Олимпиец (награда за прохождение) | `OLYMPUS`, `ОЛИМП` | +10% к урону, здоровью и броне |

## Управление

| Компьютер | Действие |
|---|---|
| ЛКМ по земле / врагу | идти / атаковать |
| Shift + ЛКМ | атака на месте |
| ПКМ | умение из первой ячейки |
| WASD | движение |
| 1–8 | умения |
| Q / E | зелья здоровья / энергии |
| F | торговец, оракул, обелиск |
| Alt | показать подписи всех предметов |
| I / C / K / J / M / Esc | снаряжение, герой, умения, задания, карта, пауза |

## Разработка

Исходники лежат в `src/` (данные, мир, графика, игра, рендер, интерфейс). Собрать `index.html`:

```
node build.mjs
```
